# Operator commands

Run from root through `npm run db:migrate`, `npm run db:test:prepare`, `npm run admin:provision`. `migrate.ts --test` validates the exact test database name; normal migration targets only graphway_dev. `provision-admin.ts` generates credentials into ignored `.local/admin-access.json`, restricts ACL before writing secrets and never logs them. Existing admin and artifact remain unchanged; provisioning accepts no credential arguments.

The single optional `--test` flag targets only validated graphway_test and writes `.local/test-admin-access.json`, never the development credential artifact. `NODE_ENV=test` server runtime selects TEST_DATABASE_URL and TEST_PORT (default 3002) after importing the existing six runtime keys; only the isolated loopback test origin is accepted.

Production: root `npm run db:migrate:production` and `npm run admin:provision:production` use the built Node CLI, no tsx. Both require exact `NODE_ENV=production` plus `--production`, `DATABASE_URL` pathname `/graphway_prod`; missing/mixed/duplicate/unknown flags fail before local import or SQL. No username restriction is imposed by the CLI: use protected migrator env/`graphway_migrator` only for migration and runtime env/`graphway_prod_app` for admin/application. The runtime role has table DML/readiness SELECT only, no DDL or migrator membership.

`environment.ts` centralizes the mode/database guards. `admin-artifact.ts` validates required absolute `ADMIN_CREDENTIALS_PATH` against canonical release root (including symlinked parent), checks native owner0700 parent, and exclusively creates0600 before any credential write; Windows ACL policy is preserved. Production parent must already exist outside release, e.g. `/var/lib/graphway/private`; no `.local` fallback or automatic parent creation. Admin credentials are generated by the existing singleton transaction and never printed/accepted in arguments. Repeated provisioning preserves existing admin/artifact. Both source and built commands establish release root independently of caller cwd.
