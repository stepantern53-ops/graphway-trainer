# Server

- `src/`: same-origin Express API, работа с PostgreSQL, аутентификация и проверка доступа к трассам.
- `migrations/`: версионированные SQL-миграции Drizzle; во время работы приложение не создаёт таблицы.
- `tests/`: последовательные интеграционные тесты на отдельной тестовой базе.
- `drizzle.config.ts`: конфигурация генерации схемы.

Команды: `npm run db:migrate`, `npm run db:test:prepare`, `npm run admin:provision`. Учётные данные администратора создаются в приватном файле вне репозитория и не печатаются в консоль и аргументы команд.

Тесты используют тот же сервер в `NODE_ENV=test`, отдельную базу и отдельный порт. Существующие аккаунты не сбрасываются молча.

Production работает только с переменными окружения, переданными извне. Сборка создаёт `dist/index.js`, `dist/cli/migrate.js` и `dist/cli/provision-admin.js`. Миграции и создание администратора требуют явного production-режима и отдельной базы; миграционная и рабочая роли различаются, рабочая роль не имеет прав на изменение схемы. Файл с учётными данными администратора требует абсолютного пути вне каталога сборки, существующего закрытого каталога и эксклюзивного создания.
