# Public assets

Vite copies these files unchanged into `apps/web/dist`. `manrope-OFL.txt` is the installed Manrope font's SIL OFL 1.1 notice; `katex-MIT.txt` is the installed KaTeX MIT notice. Font CSS/assets are bundled locally, without external font services. Robot fallback is owned in `src/robot`, not a whole-application screenshot.
