# scripts - обслуживание локальной среды

- `local-env.ps1` - создаёт локальные секреты (Initialize), создаёт роль и две базы (Provision) и загружает переменные окружения в процесс. Значения не печатает и не меняет системное окружение.
- `local-runtime.mjs` - читает те же переменные через PowerShell и передаёт их дочернему процессу только в памяти.
- `local-db.mjs` - поднимает PostgreSQL через Docker Compose и ждёт настоящей готовности базы.
- `dev.mjs` - запускает backend и Vite одновременно для разработки.
- `test-unit.mjs` - запускает выбранный проект тестов без серверных.
- `e2e.mjs` - поднимает собственный тестовый backend на отдельном порту и отдельной базе.
- `smoke.mjs` - проверяет готовность, права роли базы и короткий пользовательский путь.

## Порядок первого запуска

```powershell
./scripts/local-env.ps1 -Action Initialize
docker compose -f compose.graphway.local.yml up -d
./scripts/local-env.ps1 -Action Provision
npm run db:migrate
npm run build
npm start
```

После первой настройки достаточно `docker compose ... up -d` и `npm start`.

## Правила безопасности

- Локальные секреты лежат вне репозитория; не выводить их в консоль, логи и аргументы команд.
- Не использовать `docker compose down -v`: это уничтожит данные.
- Тестовая база отдельная. Прогоны тестов не должны очищать рабочую базу.
- `NODE_ENV=production` не использует локальный загрузчик переменных и работает только с внешним окружением.
